SPARSE RULE EVALUATION:
─────────────────────────
Input: "Parent[A,B]. Ancestor[x,y] = Parent[x,y]."
   │
   ├──► Parser ──► IRProgram
   │
   ├──► TLContext.declare_relation(:Parent)
   │
   ├──► TLContext.add_tuple(:Parent, (A, B))
   │
   ├──► Engine.run! (fixpoint iteration)
   │        │
   │        ├──► Apply rules until convergence
   │        │
   │        └──► Store new tuples
   │
   └──► Query: relation_tuples(ctx, :Ancestor) ──► [(A, B)]


DENSE EXPRESSION EVALUATION:
───────────────────────────
Input: "exists y:Person. knows(x,y)"
   │
   ├──► Parser ──► ExistsExpr
   │                   │
   │                   ├─ var: y
   │                   ├─ domain: Person
   │                   └─ body: Pred(:knows, [x, y])
   │
   ├──► Compiler Context
   │        │
   │        ├─ domains: {Person → 5}
   │        └─ predicates: {knows → [Person, Person]}
   │
   ├──► Validator ──► Check domains, arities ──► ✓
   │
   ├──► eval_dense(expr, ctx; config=soft_differentiable())
   │        │
   │        ├──► Get input tensor for 'knows' (5×5)
   │        │
   │        ├──► Apply soft max over y dimension
   │        │
   │        └──► Return LabeledTensor (5,) for each x
   │
   └──► Output: Tensor of shape (5,) with differentiable values
